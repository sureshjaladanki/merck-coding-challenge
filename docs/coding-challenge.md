# Merck KGaA | Healthcare Digital, Data & IT R&D | Coding Challenge

## Senior Frontend Engineer - Challenge

### Objective

Create a simple web application using TypeScript and Next.js that demonstrates your ability to build a user interface, interact with a mock API, and apply best practices in coding, performance optimization, and user experience design. The architecture of the application shall allow handling of large amounts of data (even if only a small data set is used for this exercise). Please include testing and documentation.

### Challenge Overview

You will develop a small application that allows users to view, search, and filter a list of drug candidates. The application should interact with a mock API to fetch data and display it in a user-friendly manner.

Please note that the candidate is expected to demonstrate a running code in the code walk through session.

### Requirements

#### Setup

- Use Next.js as the framework for the application.
- Use TypeScript for type safety.
- Use Tailwind CSS for styling.

#### Functionality

- Create a homepage that displays a list of drug candidates with the following fields: Name, Status (e.g., In Development, Approved), and Description.
- Implement a search bar to filter the list of drug candidates by name.
- Allow users to click on a drug candidate to view more detailed information on a separate page (e.g., a details page with additional fields like Mechanism of Action, Side Effects, etc.).
- Mock the API interaction using a JSON file or a simple in-memory data structure to simulate fetching data from an API.
- Ensure to document the code and your approach to the solution.
